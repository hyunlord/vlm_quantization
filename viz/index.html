Current-pipeline anatomy — interactive

Exploratory views of what the frozen-SigLIP2 → Matryoshka head → 1024-bit sign code actually does, across three text paths (ceiling / distillation / head-adapt). Drag sliders, toggle paths, hover. Math: docs/FORMULATION.md. Data: viz/data/*.json (regenerate via scripts/viz_data.py).

1 · forward_stages

One sample's 1024-d vector at each stage e→s(sliced)→BN→L2 z→sign. Path + sample slider; overlay paths. Where the distribution narrows/standardizes.

2 · distribution_explorer

|z| histogram, per-bit +1 balance, 64×64 bit-bit correlation. Toggle BatchNorm on/off and overlay paths.

3 · sign_information_loss

Same query ranked by continuous z·z vs Hamming, gold highlighted, bit slider 64/256/1024. What binarization reorders.

4 · embedding_space

Precomputed PCA/UMAP of SigLIP embedding, code space, and 12 languages. Toggle space/projection; color by modality-path / language.

5 · retrieval_anatomy

Per query: Hamming-to-gallery histogram with gold vs nearest-wrong markers (negative separation), and a 32×32 grid of which bits differ from the correct image.

Serve locally (not file://, the pages fetch JSON):
cd viz && python -m http.server 8800 → open http://localhost:8800/
