Subspace Overlap Analysis

overlap = mean cos² of principal angles between top-k PCA subspaces (1=identical, 0=orthogonal) random baseline = expected overlap for random subspaces of same dimensionality  ·  Tests whether the low-dim retrieval subspace is shared across modalities and languages.

한국어 해설 (Korean explainer)

📊 무엇을 보는가

검색에 쓰이는 저차원 부분공간이 모달(이미지↔텍스트) 간, 언어 간 '공유'되는지 측정합니다. 이미지-only PCA 부분공간과 텍스트-only PCA 부분공간의 주각(principal angle) 겹침(cos² 평균; 1=동일, 0=직교)과, 두 모달을 이미지/텍스트/결합 basis에 투영했을 때의 R@10을 봅니다.

🔍 어떻게 읽나

Panel1: 겹침이 random(점선)보다 한참 위면 공유가 있는 것. Panel2: 어느 basis가 검색을 잘 살리나 — 텍스트 basis가 결합과 비슷하고 이미지 basis는 손해. Panel3: 언어별 텍스트 부분공간이 영어/이미지와 얼마나 겹치나(k=64).

👀 주목점

이미지·텍스트는 부분적으로 공유(@64 ≈0.40, random ~0.06의 6-8배; @256 ~0.6)하나 동일하진 않습니다. ★비대칭: 교차모달 검색 신호는 '텍스트 주성분 부분공간'에 훨씬 더 정렬됩니다(텍스트 basis R@10 ≈ 결합 ≫ 이미지 basis; so400m@64 66.6 vs 27.7) → 이미지의 고분산 방향은 검색 방향이 아님. 언어들은 영어와 텍스트 부분공간을 강하게 공유(중앙값 0.67)하며 이미지와의 공유(0.33)보다 큼. 약한 언어(te 0.13)는 공유가 낮습니다 → 약함 = 공통 부분공간에 못 들어감.

🔗 연결

Section3('소수 차원이 무엇인가')의 답: 저차원 구조는 모달·언어 공통 부분공간으로 일부 실재합니다(저차원 집중 서사 중 그나마 견고한 부분). 단 모달 간은 비대칭(텍스트 주도)이고 언어 간은 강함. 3 backbone 일관. dim_vs_recall/spectrum_explorer와 함께 보세요. 탐색용 — 단정 대신 수치로.
