📊 무엇을 보는 갤러리인가

이 갤러리는 텍스트→이미지 검색 실패 케이스를 사람이 직접 확인하기 위한 도구입니다. 현재 ceiling 모델의 실패율은 약 20.1%로 추정되며, 그 중 confusable(근접오답) ≈ 12.8%(전체의 약 64%), isolated(고립) ≈ 7.3%(전체의 약 36%)로 분류되어 있습니다. 이 수치는 Hamming 거리 임계값(226)에 기반한 추정치이며, 아래 A/B 판단으로 보정됩니다.

🔍 어떻게 읽나

  • 각 행 = 쿼리 캡션 1개 + 썸네일 4장 (정답 1 + 검색 상위 3)
  • 초록 테두리: 정답(GOLD) 이미지 — 모델이 gold_rank 위치로 밀어낸 이미지
  • 나머지 3장: 모델이 실제로 가장 먼저 검색해온 (인스턴스 기준 오답) 이미지
  • ham = Hamming 거리 (작을수록 모델이 더 가깝다고 판단)
  • rank = 전체 검색 결과 내 순위 (1이 가장 근접)

👀 주목할 점

  • A (라벨한계 후보): 검색1/2/3 이미지가 캡션 내용과 시각적·의미적으로 유사 → instance R@K가 의미 중복 이미지를 오답 처리했을 가능성
  • B (고립 후보): 검색 결과가 캡션과 전혀 무관한 장면 → 모델이 실제로 잘못 매핑한 새로운 실패 유형
  • amber 배지(근접오답 존재)는 임계값 기반 분류이고, red 배지(고립)은 그 반대입니다. 최종 판단은 사람이 합니다.

🔗 연결 맥락

A가 많으면 → 평가지표(instance R@K) 보정 여지가 있고, 모델 실제 성능은 수치보다 높을 후보입니다.
B가 많으면 → 새로운 실패 모드(고립 케이스)가 유의미하게 존재하며 추가 분석이 필요합니다.
이 갤러리는 후보 판별을 위한 보조 도구이며, 결론은 사람의 최종 확인을 통해 도출됩니다.
